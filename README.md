# 대포 뽑기

수업 시간에 번호로 발표자나 순서를 뽑는 웹페이지입니다. 화면에 번호 과녁이 깔리고, 대포가 조준하다가 한 곳을 쏘면 그 번호가 당첨됩니다.

설치 없이 `index.html` 파일 하나를 브라우저로 열면 됩니다.

## 쓰는 법

- 위쪽 **인원** 칸에 학급 인원(2~60)을 넣습니다.
- 결석한 번호는 과녁을 한 번 눌러 뺍니다. 다시 누르면 돌아옵니다.
- **발사!** 버튼이나 스페이스 키로 쏩니다.
- **뽑힌 번호 빼기**를 켜 두면 한 번 뽑힌 번호는 모두 뽑힐 때까지 다시 나오지 않습니다.
- 뽑힌 번호를 잘못 눌렀다면 그 과녁을 누르면 기록에서 지워집니다.
- **처음부터**를 누르면 뽑기 기록이 지워집니다. 인원과 결석 표시는 남습니다.

인원, 결석 번호, 뽑기 기록은 그 컴퓨터의 브라우저에 저장됩니다. 다른 컴퓨터에서 열면 처음 상태로 시작합니다.

TV, 전자칠판처럼 가로 화면과 세로 모니터 모두 화면 크기에 맞춰 과녁 크기가 바뀝니다. 효과음은 브라우저에서 직접 만들기 때문에 따로 소리 파일이 필요 없습니다.
