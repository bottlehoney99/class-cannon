# 한 명 뽑기

수업 시간에 번호로 발표자나 순서를 한 명씩 뽑는 웹페이지입니다. 설치 없이 `index.html` 파일 하나를 브라우저로 열면 됩니다.

위쪽 탭에서 뽑기 방식을 고릅니다. 어느 방식이든 버튼을 누르고 3~4초 안에 결과가 나옵니다.

| 탭 | 움직임 |
| --- | --- |
| 대포 | 대포가 번호 과녁 사이를 조준하다가 한 곳을 쏩니다. |
| 인형뽑기 | 집게가 번호표를 단 인형 하나를 집어 배출구로 옮깁니다. |
| 캡슐 뽑기 | 손잡이를 돌리면 캡슐 하나가 굴러 나와 열리고 번호가 나옵니다. |
| 낚시 | 헤엄치던 번호 물고기 한 마리가 바늘을 물고 끌려 올라옵니다. |
| 슬롯머신 | 번호 릴이 돌다가 천천히 멈춥니다. |

## 쓰는 법

- 위쪽 **인원** 칸에 학급 인원(2~60)을 넣습니다.
- 결석한 번호는 **대포** 탭에서 그 번호 과녁을 한 번 눌러 뺍니다. 다시 누르면 돌아옵니다. 결석 표시는 다른 탭에도 똑같이 적용됩니다.
- **뽑기!** 버튼이나 스페이스 키로 뽑습니다.
- **뽑힌 번호 빼기**를 켜 두면 한 번 뽑힌 번호는 모두 뽑힐 때까지 다시 나오지 않습니다. 탭을 바꿔도 뽑기 기록은 이어집니다.
- **처음부터**를 누르면 뽑기 기록이 지워집니다. 인원과 결석 표시는 남습니다.

인원, 결석 번호, 뽑기 기록은 그 컴퓨터의 브라우저에 저장됩니다. 다른 컴퓨터에서 열면 처음 상태로 시작합니다.

TV, 전자칠판 같은 가로 화면과 세로 모니터 모두 화면 크기에 맞춰 배치가 바뀝니다. 효과음은 브라우저에서 직접 만들기 때문에 따로 소리 파일이 필요 없습니다.
